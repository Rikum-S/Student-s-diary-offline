#Student's diary offline
Student's diary offline is an application for creating your own unique schedule for the week, including even and odd days starting from a specific day.

Features:
• Create a schedule: the name of the subject, the name of the teacher, homework, the time of the beginning of the discipline and the time of the end, the audience, the type of lesson and frequency (every week, even week, odd week or once).
• Task Planning: Create reminders about homework, projects, and other long-term tasks.
• Customize the theme and create a widget on the phone's home screen for easy schedule display in a prominent place.

Requirements:
• Android system.
• 3-20 MB of free space.
• The desire to fill out the schedule.

Installation:
• Download the apk file and install it on your gadget.

Usage:
• Set the start date of the semester.
• Add several disciplines by specifying the full name of the teacher for the discipline (you can edit it).
• Add the created item to the schedule and specify the time and place of the discipline providence.
